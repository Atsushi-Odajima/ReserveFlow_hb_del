サンプル事業者「Sample Studio」について
==================================================
動作確認用の架空の事業者です。実在の店舗・人物とは関係ありません。
サンプル事業者ではメールは一切送信されません（実在するお客様への誤送信防止）。
本番で使うときは、サンプルとは別に自分の事業者を登録してください。

■ 作成方法（開発者向け）
  npm run seed:sample
  オーナー：owner@sample.invalid / sample-password-123
  スタッフ（Aki）：aki@sample.invalid / sample-password-123
  予約ページ：/book/sample-studio

■ 内容
 ・営業時間：毎日10:00〜19:00、水曜定休。臨時休業（設備点検）1日、短縮営業1日
 ・サービス
    30分オンライン相談（片付け10分）
    60分個人レッスン（準備15分・片付け15分、Room A 必須）
    90分撮影（準備15分・片付け15分、Studio B と Camera Set 1 が必須）
    6名定員ワークショップ（開催日程から選ぶ、毎週土曜13:00、1予約最大3名、Room A）
 ・スタッフ：Aki（勤務9:30〜19:00、休憩12:30〜13:30／レッスン・ワークショップ・相談）
             Mika（営業時間に従う／撮影・相談・レッスン、近日に午後半休あり）
 ・リソース：Room A（定員8）、Studio B、Camera Set 1（メンテナンスのブロックあり）
 ・事前質問：「ご利用は初めてですか？」（必須・選択）、撮影のイメージ（撮影のみ）、キャンセル規定の確認（必須チェック）
 ・予約データ：完了・無断欠席（過去）、通常の予約、日時を変更した予約、お客様都合のキャンセル、
   キャンセルで空いた枠に合う待機リスト、ワークショップ定員6のうち5名予約済み（残り1名）
 ・二重予約の競合：データとしては作れない（システムが防ぐ）ため、予約ページを2つのブラウザで開き、
   同じ時間を同時に確定して「1件だけ成功し、もう一方に別の時間が案内される」ことを確認してください。

■ 試してみること
 1. /book/sample-studio で「60分個人レッスン」を予約 → 管理画面で確認
 2. Aki の休憩時間・Mika の半休の時間帯に空きが出ないことを確認
 3. ワークショップを2名で予約しようとすると満席、1名なら予約できることを確認
 4. 「待機リスト」で空きありの候補を確認
