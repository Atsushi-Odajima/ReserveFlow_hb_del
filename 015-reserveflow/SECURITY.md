# セキュリティ（SECURITY）

## 認証・セッション
- パスワード：scrypt（N=16384,r=8,p=1、16byte salt）。10 文字以上。
- ログイン失敗 8 回で 15 分ロック。IP 単位 30 回/15 分、ユーザー単位 10 回/15 分のレート制限。存在しないユーザーでも同等の計算時間。
- セッション：256bit ランダムトークンを HttpOnly・SameSite=Lax・Secure（本番）Cookie に保存。DB には SHA-256 のみ。14 日有効。
  パスワード変更時は他セッションを削除。メンバー削除時はそのセッションを削除。
- CSRF：管理 API の GET 以外は `X-CSRF-Token`（セッション固有）必須＋SameSite=Lax。公開/管理リンク API は Cookie 認証を使わないため CSRF 対象外。
- 新規登録は本番では既定で無効（`ALLOW_SIGNUP=false`）。

## 認可・事業者間分離
- すべての管理 API はサーバー側でセッションの事業者に限定（`business_id = $session`）。ID を推測しても他事業者の行は 404。
- 参照 ID（スタッフ・リソース・サービス・顧客）は保存前に同一事業者か検証（`assertOwned`）。DB でも複合外部キー。
- スタッフ権限：既定は「自分の担当予約のみ閲覧・操作」「顧客閲覧」「予約作成/変更/キャンセル」「自分の休み登録」。
  オーナーが個別に変更可。設定・サービス・スタッフ・リソース・CSV・バックアップ・監査・分析はオーナーのみ。強制予約はオーナーのみ。
- 結合テスト `tests/integration/security.test.ts` で読み書き双方の越境を検証。

## 公開予約ページ
- 公開 API が返すのは明示的に選んだ公開項目のみ（内部名・スタッフのメール・メモ・リソース ID・顧客/予約 ID は返さない）。
  サービス/スタッフの UUID は選択のため公開識別子として扱う（推測されても他情報は得られない）。
- 予約番号（ref_code）はお問い合わせ用の表示番号で、これだけでは何も閲覧できない。
- bot/大量予約対策：IP 10 件/10 分、事業者 300 件/時、同一メール 10 件/日、ハニーポット項目、送信最短 2.5 秒、任意 Turnstile。
- 事業者が非公開にしたページは 404。

## 予約管理リンク
- 256bit トークン、SHA-256 のみ保存、URL フラグメントで受け渡し（アクセスログ・Referer に出ない）。画面表示後は sessionStorage に移しアドレスバーから除去。
- 期限：予約終了 +30 日。再発行で既存トークンを失効。レート制限 60 回/分/IP。形式不正は即拒否。

## 入力・出力
- 全 API 入力を Zod で検証（型・長さ・列挙・日付形式）。
- SQL はすべてプレースホルダ（検索の LIKE はワイルドカードをエスケープ）。
- XSS：React のエスケープのみ使用（`dangerouslySetInnerHTML` 不使用）。CSP `default-src 'self'; script-src 'self'; object-src 'none'; frame-ancestors 'none'` 等。
- メールは plain text のみ、件名・変数から制御文字除去（ヘッダインジェクション不可）。ICS はテキストエスケープ。
- CSV：UTF-8 BOM、数式インジェクション対策（先頭記号に ' を付与）。
- ロゴ画像：PNG/JPEG/WebP のマジックバイト検証、256KB 上限、`nosniff`。
- セキュリティヘッダ：X-Frame-Options DENY, nosniff, Referrer-Policy（管理リンク/招待は no-referrer）, Permissions-Policy, COOP, HSTS（本番）。

## 秘密情報
- `APP_SECRET`・`DATABASE_URL`・`SMTP_URL` は環境変数のみ（リポジトリに含めない。`.env` は .gitignore）。
- 本番起動時 `APP_SECRET` 32 文字未満はエラー。
- ログ：Fastify のリクエストログで Cookie・CSRF ヘッダを伏字化。管理トークンは URL に出ないためログに残らない。
- 監査ログにはトークン・パスワード・質問回答全文を入れない（件数・ID・変更項目名のみ）。

## 監査ログ（audit_logs）
予約作成/強制作成/変更/キャンセル/状態変更/メモ、管理リンク再発行、ブロック作成/削除、設定・営業時間・例外・サービス・スタッフ・リソース・質問の変更、
メンバー招待/権限変更/削除、ログイン、CSV 出力/取込、バックアップ作成/復元、通知再送、顧客の作成/更新/アーカイブ/エクスポート/削除（匿名化）。

## プライバシー
- 収集項目は氏名・メール・電話（任意/必須/非表示を選択）・事前質問のみ。医療問診用途は非推奨と画面・説明書に明記。
- 顧客データのエクスポート（開示請求）と削除（匿名化）機能あり。バックアップファイルには個人情報が含まれる旨を画面で注意喚起。
- 法令適合（個人情報保護法等）を保証するものではない。プライバシーポリシーの整備は購入者の責任（注意事項.txt）。
